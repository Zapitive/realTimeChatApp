# Realtime Chat Application
A full-stack chat application using MERN, with JWT authentication and sockets for real time chatting. It uses Tailwindcss for styling clean UI.

## 🚀 Features (up unitl now)
- **JWT authentication**
- **Refresh token system**
- **MongoDB TTL for token expiry**
- **Password hashing with bcrypt**
- **Secure API routes**

2. **Frontend**
    - React
    - TailwindCss
3. **Authentication**
